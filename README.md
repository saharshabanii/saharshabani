# Sahar Shabani academic website

Static academic job-market website for saharshabani.com.

## Publish on GitHub Pages
Upload all files in this folder to the root of the `saharshabani` repository. In GitHub: Settings → Pages → Deploy from a branch → `main` / `(root)`. The `CNAME` file is already set to `saharshabani.com`.

The domain's DNS records will be connected after GitHub Pages is enabled.
